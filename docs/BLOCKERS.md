# Blockers & Known Issues

Track anything that blocks progress or needs user/owner input here, with what was
tried and what is needed to unblock.

## Open

- **Gmail OAuth credentials required for live sync.** `gmail_service` needs
  `config/gmail_credentials.json` and a one-time OAuth consent to populate the
  Keychain token. Without it, email sync is inert (the scheduler logs a warning
  and continues). *Needed:* a Google Cloud OAuth client + first-run consent.
- **AI features require an API key.** `AI_ENABLED=true` needs `AI_API_KEY`. With
  AI disabled, the AI fallback parser and Layer 3b category classification are
  skipped (structured parsers + cached mappings still work).

## Resolved

- **FastAPI app failed to import** — `Optional` was used but not imported in
  `api/routes/tags.py` and `routes/failed_emails.py`, so `import backend.api.main`
  raised `NameError`. Fixed by adding the missing imports.
- **Missing `rapidfuzz` dependency**, **broken AI-module imports/config**, and an
  **empty parser registry** — fixed (see PR #1).
- **Subscription detection ignored time intervals** — reworked to
  interval-regularity clustering (§5.8).

## Notes

- The initial Alembic migration (`4437f5f2154e`) is a partial autogenerated
  artifact; the working schema is created by `init_db()` (`create_all`). New
  migrations (e.g. the budgets table) are hand-written and consistent. Consider
  regenerating a clean baseline migration in a future cleanup.
